Đây là Project về Môn Java Nâng cao. Học dự án lập trình Web với mô hình MVC với các công nghệ như : Tomcat, Servlet, JDBC với ngôn ngữ Java 
Project về một Website về một trang xem phim trực tuyến với các chức năng cơ bản cho việc xem phim như :
- Đăng ký
- Đăng nhập
- Phân quyền đăng nhập đối với User / Admin
- Có lưu thông tin xem của các loại phim
- Chức năng yêu thích, chia sẻ phim mà mình yêu thích
- Phân trang , giao diện thân thiện, hiện đại và hợp mắt đối với việc xem phim
- Giao diện được tối ưu
